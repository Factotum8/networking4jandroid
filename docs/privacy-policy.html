Политика конфиденциальности приложения networking4j

Дата вступления в силу: 3 ноября 2026 г.

Коротко

Приложение networking4j работает полностью офлайн. Оно не собирает, не передаёт и не имеет технической возможности передавать какие-либо данные пользователя куда-либо за пределы устройства.

Какие данные обрабатывает приложение

Приложение хранит на устройстве пользователя (в локальной базе данных SQLite/Room) только те данные, которые пользователь сам вводит в приложении: контакты, заметки о них, даты, теги и связанные с ними записи (взаимодействия, задачи-напоминания). Эти данные никогда не покидают устройство — приложение не выполняет сетевых запросов, не использует облачную синхронизацию, аналитику, рекламные SDK или сервисы сбора крэш-репортов сторонних компаний.

Разрешения

Приложение не запрашивает доступ к хранилищу, контактам, местоположению, камере, микрофону или любым другим системным разрешениям. Импорт, экспорт и резервное копирование данных (CSV/vCard/JSON) выполняются только через системный диалог выбора файла (Storage Access Framework) — приложение получает доступ ровно к тому файлу, который пользователь явно выбрал в диалоге, и ни к чему больше.

Передача данных третьим лицам

Приложение не передаёт никакие данные третьим лицам, потому что оно не имеет сетевого доступа в принципе.

Хранение и удаление данных

Все данные хранятся локально на устройстве пользователя до тех пор, пока пользователь не удалит их внутри приложения, не очистит данные приложения через настройки Android, либо не удалит само приложение — любое из этих действий полностью удаляет все данные без возможности восстановления. Перед удалением пользователь может сделать резервную копию (JSON/CSV) через раздел «Импорт/экспорт» приложения и сохранить её в любом удобном месте по своему усмотрению.

Дети

Приложение не предназначено для детей и не собирает данные от лиц, о которых приложению было бы известно, что они не достигли возраста цифрового согласия.

Изменения политики

При изменении политики конфиденциальности дата вступления в силу наверху страницы будет обновлена.

Контакты

По вопросам, связанным с этой политикой, создайте обращение в репозитории проекта: https://github.com/Factotum8/networking4jandroid/issues.
