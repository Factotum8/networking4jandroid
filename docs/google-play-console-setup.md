# Доступ в Google Play Console — чек-лист

> Составлено 2026-09-22. Эти шаги выполняются только вручную (нужны ваши
> платёжные данные и документ, удостоверяющий личность) — ассистент их
> сделать не может. Цель — дойти до возможности загрузить приложение во
> **внутренний тестовый трек (internal testing)**, чтобы установить его на
> свой телефон через Play Store.

## 1. Регистрация аккаунта разработчика

- [x] Перейти на **play.google.com/console/signup**
- [x] Войти под Google-аккаунтом (обычный Gmail или Google Workspace на
      вашем домене, если есть)

## 2. Выбрать тип аккаунта

- [x] **Personal (личный)** — публикация от вашего имени как физлица, проще
      верификация — вероятно, подходящий вариант для этого проекта
- [ ] или **Organization (организация)** — публикация от имени компании,
      требует D-U-N-S номер и юридические документы — дольше и
      бюрократичнее

*(отметьте, какой выбрали — влияет на то, кто по документам "владеет"
публикацией в будущем)*

## 3. Оплата

- [x] Разовый регистрационный взнос **$25**, картой через Google Payments

## 4. Профиль разработчика

- [x] Имя разработчика (публично видно в Store)
- [x] Контактный email — `[email removed]` (тот же, что в
      Privacy Policy — [`docs/privacy-policy.html`](./privacy-policy.html))
- [x] Телефон

## 5. Верификация личности — **самый долгий шаг, начать в первую очередь**

- [x] Загрузка документа, удостоверяющего личность (и/или видео-звонок для
      личных аккаунтов; D-U-N-S проверка для организаций)
- [x] Дождаться подтверждения — может занять от нескольких часов до
      нескольких дней

## 6. Создать приложение в консоли

- [x] `Create app` → указать package name: **`com.factotum8.networking4jandroid`**
      (менять после создания нельзя!)
- [x] Название приложения (сейчас в манифесте: `networking4j` — можно
      изменить только для Store-листинга, не трогая код)

## 7. Обязательные разделы App content (заполняются до первого релиза)

- [ ] **Privacy Policy URL** — после включения GitHub Pages:
      `https://factotum8.github.io/networking4jandroid/privacy-policy.html`
      (или `-en.html` для английской версии)
- [ ] **Data safety** — форма о данных (у нас: данные не собираются и не
      передаются, всё хранится локально)
- [ ] **Content rating** questionnaire (IARC)
- [ ] **Target audience** (возрастная группа)
- [ ] **Ads declaration** — рекламы нет
- [ ] Government apps / COVID-19 apps — не применимо

## 8. Загрузка сборки во внутренний тест

- [x] Настроить `signingConfig` в `app/build.gradle.kts` (upload keystore,
      пароль из 1Password, хранилище `networking4j`)
- [x] Собрать `.aab`: `./scripts/bundle-release.sh` →
      `app/build/outputs/bundle/release/app-release.aab`
- [ ] Загрузить в **Internal testing** track
- [ ] Добавить себя как тестировщика по email
- [ ] Открыть ссылку-приглашение на телефоне → принять → установить через
      Play Store

**Важно:** требование Google "closed testing минимум 12+ тестировщиков 14
дней подряд" действует только при продвижении в **production**, на
**internal testing** оно не распространяется — туда можно загрузить сборку
сразу после верификации аккаунта (шаг 5), без дополнительных условий.
