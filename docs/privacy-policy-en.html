Privacy Policy — networking4j

Effective date: November 3, 2026

In short

networking4j works fully offline. It does not collect, transmit, or have any technical ability to transmit user data anywhere off the device.

What data the app processes

The app stores, on the user's device only (in a local SQLite/Room database), the data the user enters into the app themselves: contacts, notes about them, dates, tags, and related records (interactions, reminder actions). This data never leaves the device — the app makes no network requests and uses no cloud sync, analytics, advertising SDKs, or third-party crash-reporting services.

Permissions

The app does not request access to storage, contacts, location, camera, microphone, or any other system permission. Import, export, and backup of data (CSV/vCard/JSON) are performed only through the system file picker (Storage Access Framework) — the app gets access to exactly the one file the user explicitly picked in that dialog, and nothing else.

Sharing data with third parties

The app does not share any data with third parties, because it has no network access to begin with.

Data retention and deletion

All data stays on the user's device until the user deletes it inside the app, clears the app's data via Android settings, or uninstalls the app — any of these fully and irrecoverably deletes all data. Before deleting, the user can make a backup (JSON/CSV) via the app's "Import/Export" section and save it wherever they choose.

Children

The app is not directed at children and does not knowingly collect data from anyone below the age of digital consent.

Changes to this policy

If this policy changes, the effective date at the top of this page will be updated.

Contact

For questions about this policy, open an issue in the project repository: https://github.com/Factotum8/networking4jandroid/issues.
