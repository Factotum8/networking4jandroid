# Доступ в Google Play Console — чек-лист

> Составлено 2026-09-22. Эти шаги выполняются только вручную (нужны ваши
> платёжные данные и документ, удостоверяющий личность) — ассистент их
> сделать не может. Цель — дойти до возможности загрузить приложение во
> **внутренний тестовый трек (internal testing)**, чтобы установить его на
> свой телефон через Play Store.

## 1. Регистрация аккаунта разработчика

- [x] Перейти на **play.google.com/console/signup**
- [x] Войти под Google-аккаунтом (обычный Gmail или Google Workspace на
      вашем домене, если есть)

## 2. Выбрать тип аккаунта

- [x] **Personal (личный)** — публикация от вашего имени как физлица, проще
      верификация — вероятно, подходящий вариант для этого проекта
- [ ] или **Organization (организация)** — публикация от имени компании,
      требует D-U-N-S номер и юридические документы — дольше и
      бюрократичнее

*(отметьте, какой выбрали — влияет на то, кто по документам "владеет"
публикацией в будущем)*

## 3. Оплата

- [x] Разовый регистрационный взнос **$25**, картой через Google Payments

## 4. Профиль разработчика

- [x] Имя разработчика (публично видно в Store)
- [x] Контактный email (в репозитории не храним; в Privacy Policy —
      [`docs/privacy-policy-en.html`](../docs/privacy-policy-en.html) —
      контакт через GitHub Issues)
- [x] Телефон

## 5. Верификация личности — **самый долгий шаг, начать в первую очередь**

- [x] Загрузка документа, удостоверяющего личность (и/или видео-звонок для
      личных аккаунтов; D-U-N-S проверка для организаций)
- [x] Дождаться подтверждения — может занять от нескольких часов до
      нескольких дней

## 6. Создать приложение в консоли

- [x] `Create app` → указать package name: **`com.factotum8.networking4jandroid`**
      (менять после создания нельзя!)
- [x] Название приложения (сейчас в манифесте: `networking4j` — можно
      изменить только для Store-листинга, не трогая код)

## 7. Обязательные разделы App content (заполняются до первого релиза)

Где: приложение networking4j → **Правила и программы → Контент приложения**.
Ответы подготовлены 2026-11-03 и сверены со сборкой: в APK нет разрешения
`INTERNET`, нет сетевых/аналитических/рекламных SDK; единственное
разрешение — служебное `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` от
`androidx.core`.

- [x] **Политика конфиденциальности** — URL:
      `https://factotum8.github.io/networking4jandroid/privacy-policy-en.html`
      (GitHub Pages, ветка `main`, папка `/docs`)
- [x] **Доступ к приложению** — все функции доступны без специального
      доступа (нет входа/аккаунтов)
- [x] **Реклама** — нет рекламы
- [x] **Возрастные ограничения (IARC)** — email анкеты: gmail (не
      публикуется); категория «Другие типы приложений» (All Other App
      Types); насилие/секс/лексика/наркотики/азартные игры/юмор — нет;
      общение или обмен контентом между пользователями — нет; передача
      местоположения — нет; цифровые покупки — нет. Ожидаемо 3+ / Everyone
- [x] **Целевая аудитория** — только 18+ (младше 13 включает требования
      программы для семей); привлекает детей — нет
- [x] **Безопасность данных (Data safety)** — собирает/передаёт данные —
      **нет** (по определению Google «сбор» = передача с устройства; экспорт
      через системный выбор файла делает сам пользователь — не сбор)
- [x] **Рекламный идентификатор** — не используется
- [x] **Новостные приложения** — нет (в консоли 2026-11-06 такой карточки не было)
- [x] **Государственные приложения** — нет
- [x] **Финансовые функции** — не предоставляет
- [x] **Приложения для здоровья** — нет
- Карточки про разрешения на фото/видео или foreground service, если
  появятся, — не используется (таких разрешений нет)

### Статус продавца и контакты (перед шагом 8)

- [ ] **Статус продавца (DSA, ЕС)** — баннер «Задекларируйте статус
      продавца» вверху консоли; решение за владельцем аккаунта
- [ ] **Настройки для Google Play → Контактная информация для страницы
      приложения** — публичный email (виден всем в Google Play):
      `networking4j@proton.me`
  - Ящик заведён 2026-11-09 специально для приложения (Proton Mail).
  - Доступ (пароль и т.п.) — только в 1Password, хранилище `networking4j`;
    в репозитории не хранится.

## 8. Загрузка сборки во внутренний тест

- [x] Настроить `signingConfig` в `app/build.gradle.kts` (upload keystore,
      пароль из 1Password, хранилище `networking4j`)
- [x] Собрать `.aab`: `./scripts/bundle-release.sh` →
      `app/build/outputs/bundle/release/app-release.aab`
- [x] Загрузить в **Internal testing** track — 2026-11-09, выпуск `2 (0.1.0)`
      (versionCode 2, targetSdk 36: Play требует target ≥ 36; versionCode 1
      занят первой загрузкой с target 35)
- [x] Добавить себя как тестировщика по email — список рассылки
      «Internal testers» (gmail владельца консоли); новых тестировщиков
      можно добавлять в этот список в любой момент, до 100 человек
- [ ] Открыть ссылку-приглашение
      `https://play.google.com/apps/internaltest/4700196165932578078`
      на телефоне → принять → установить через
      Play Store

**Важно:** требование Google "closed testing минимум 12+ тестировщиков 14
дней подряд" действует только при продвижении в **production**, на
**internal testing** оно не распространяется — туда можно загрузить сборку
сразу после верификации аккаунта (шаг 5), без дополнительных условий.
